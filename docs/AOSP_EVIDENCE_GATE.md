# AOSP evidence artifact gate

This offline checker verifies **artifact presence and integrity**, not authenticity of a Cuttlefish device or successful Android build.

Required evidence directory files:
- `locked-manifest.xml` — generated by a real `repo manifest -r` after checkout/sync.
- `manifest-repository-commit.txt` — source manifest git SHA.
- `manifest.sha256` — SHA-256 of `locked-manifest.xml` as a single lowercase hex digest.
- `metadata.txt` — host and checkout details.
- `cuttlefish-observations.txt` — observed adb fingerprint/boot/SELinux output.

Compute the manifest checksum:
```bash
sha256sum /path/to/evidence/locked-manifest.xml | awk '{print $1}' > /path/to/evidence/manifest.sha256
python3 tools/scripts/validate-locked-manifest.py /path/to/evidence/locked-manifest.xml
python3 tools/scripts/verify-aosp-evidence.py /path/to/evidence
```

**Critical:** A passing result only confirms the evidence directory's structure, SHA checksum and selected text fields. Stubbed data could also pass, so human review of provenance, actual build logs and device logs remains mandatory.
